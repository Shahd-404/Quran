# Wird

ورد — Arabic-first, mobile-first web app to help users maintain a daily Quran reading plan.

Status: Foundation initialized — application shell and developer tooling only.

Stack: Next.js, React, TypeScript, Tailwind CSS, Vitest, React Testing Library, npm

Prerequisites
- Node.js (LTS) and npm

Installation

```bash
npm install
```

Development

```bash
npm run dev
```

Verification

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run check
```

Important notes
- The authoritative product documentation lives in the `docs/` folder.
- This foundation does NOT implement authentication, database access, Quran content, notifications, or user features.

See `AGENTS.md` for repository rules and the development workflow.
